Settings

Mode

Test Mode uses fake, instant, free outputs for every stage - script, voice, visuals, and "publishing" - so you can click through the whole pipeline without spending anything or needing real API keys. Switch to Real Mode when you're ready to spend real money and actually publish.

Budget cap

Hard limit on total real spend. Every paid stage checks this before running - when the cap is hit, the pipeline halts cleanly with a clear message instead of drifting past it. Test-mode calls never count.

Automation level

Auto-script mode: when ON, AI drafts go straight to voice with no human edit - the only human step left is your final video approval. Be aware this increases YouTube "inauthentic content" policy risk: fully-automated AI pipelines are exactly what their 2026 enforcement targets, and channels have been terminated for it. OFF means you edit each script before production continues (safer, more work).

System check

Live diagnostics - what's configured, what's missing, what would fail. Check here first when something doesn't work.

YouTube

Shared across all channels - set this up once, then use the "Connect YouTube" button on each channel's row on the Channels page (no terminal needed).
